06 · OWNERSHIP

Next.js·Convex·Vercel은 무엇을 맡나

NEXT.JS · SURFACE

두 개의 제품 화면

  • Public Web: 소개·유입
  • App: 고객·운영자·채팅
  • 각각 독립 root와 배포
CONVEX · TRUTH

데이터와 서버 규칙

  • reactive query
  • transactional mutation
  • scheduler와 durable state
VERCEL · DELIVERY

두 Next 앱의 배포

  • Web project
  • App project
  • Convex는 별도 deployment

한 저장소라고 한 번에 원자적으로 배포되는 것은 아닙니다. [R6-R10]
